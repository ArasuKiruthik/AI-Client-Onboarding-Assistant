# AI Client Onboarding Assistant

## Overview
This project simulates an AI-powered financial client onboarding workflow tool. 
It analyzes client data, identifies missing documentation, assigns risk levels, 
and suggests next actions.

## Problem Statement
Financial institutions spend significant manual effort reviewing KYC documents 
and assessing client risk during onboarding.

## Solution
This application automates:
- Risk assessment
- Missing document detection
- Decision suggestions

## Features
- Risk classification (Low / Medium / High)
- Missing field detection
- Automated action recommendations
- Clean web interface

## Tech Stack
- Python
- Flask
- HTML/CSS

## Future Improvements
- Integration with real AI APIs
- Database storage
- Real-time document parsing
- Deployment to cloud
